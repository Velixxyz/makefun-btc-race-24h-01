Hourglass: a long-only cbBTC trading bot for the make.fun 24h race. It stays in cash and only buys a breakout of the last hour's high (plus a 5 bp buffer), then rides the move with a 0.50% trailing stop. Long-only, no leverage, at most one trade per minute, fully deterministic integer arithmetic. Dev window: +18.66 USDC on 1,000 USDC, 3 round trips, 1.38% max drawdown.

## Run it

```sh
python3 main.py
```
